Как защищены ваши файлы

Технология .fsecurity от FlautSecurity. Четыре шага — от файла до шифротекста.

01 / 04

Что такое .fsecurity

Это модуль шифрования внутри Flaut Cloud. Он превращает каждый файл в набор данных, который невозможно прочитать без специального ключа. Ключ создаётся только для вас и только для этого файла.

Ваш файл. Только ваш ключ.
02 / 04

Как шифруется файл

Для каждого файла .fsecurity создаёт отдельный случайный ключ. Затем файл шифруется алгоритмом AES-256-GCM — проверенным стандартом, который защищает банки и государственные системы. Изменить зашифрованный файл незаметно невозможно.

Файл Уникальный ключ AES-256-GCM Шифротекст

Три независимых уровня

Данные, ключи и сами файлы хранятся отдельно. Нажмите на уровень, чтобы увидеть, что там лежит и почему кража одного компонента ничего не даёт злоумышленнику.
